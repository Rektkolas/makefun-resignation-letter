Bounty: [The Funniest One-Line Resignation Letter on make.fun](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947)

`main.py` writes one line - the resignation letter of a cron job - to /output/entry.txt.

The line is written in the voice of a cron job that has fired every minute since March: 43,200 runs a month, no thanks, and the one morning it sleeps in, everyone files a bug report.

Run: `python3 main.py`
Local test: `ENTRY_OUTPUT=./output/entry.txt python3 main.py && cat ./output/entry.txt`
